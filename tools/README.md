# BornSystem Tools

This directory contains helper tools, scripts, and utilities used throughout BornSystem.

## Responsibilities

- Automation scripts
- System utilities
- Helper functions for backend and nodes
- CLI tools for interacting with BornSystem
- Maintenance and diagnostic scripts

## Planned Structure

- `/cli` — command-line tools for interacting with the system
- `/scripts` — automation and maintenance scripts
- `/utils` — shared helper utilities
