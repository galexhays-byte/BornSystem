This file defines the entire BornSystem architecture.

## 1. Project Structure (Top Level)

The BornSystem project will contain the following top-level directories:

- `/frontend` — User interface, Tailwind CSS, components
- `/backend` — Core logic, API, authentication, system services
- `/nodes` — Kali, Ubuntu, and other operational nodes
- `/docker` — Dockerfiles, images, orchestration
- `/tools` — Scripts, utilities, automation tools
- `/workflows` — GitHub Actions, CI/CD pipelines
- `/docs` — Documentation, diagrams, architecture notes

This file will describe the full structure and components of the BornSystem project:
