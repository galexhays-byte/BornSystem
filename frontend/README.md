# BornSystem Frontend

The frontend provides the user interface for interacting with BornSystem.  
It will be lightweight, fast, and focused on system control and visualization.

## Responsibilities

- Dashboard UI
- Node status and health monitoring
- Workflow execution interface
- Node action execution and orchestration control
- Authentication UI
- Real-time logs and system events
- Settings and configuration panels

## Planned Structure

- `/components` — UI components
- `/pages` — main views
- `/styles` — Tailwind CSS and global styles
- `/services` — frontend API calls
- `/utils` — helper functions
- `server.js` — optional Node-based dev server
