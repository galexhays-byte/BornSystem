# BornSystem Nodes

Nodes represent external or internal systems that BornSystem can control, monitor, or automate.

## Responsibilities

- Remote command execution
- System health monitoring
- Workflow execution
- Secure communication with backend
- Logging and reporting

## Planned Node Types

- **Kali Node** — security tools, penetration testing, scanning
- **Ubuntu Node** — general automation, scripting, system tasks
- **Windows Node** — PowerShell automation, system control
- **Custom Nodes** — user-defined environments

## Planned Structure

- `/kali` — Kali Linux node scripts and services
- `/ubuntu` — Ubuntu automation scripts
- `/windows` — PowerShell-based node logic
- `/shared` — common utilities for all nodes
